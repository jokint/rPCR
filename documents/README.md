# documents/ — figure sources for the ratioPCR manuscript

Thirteen Quarto documents, one per figure. Each is self-contained: it reads its input data
from `extdata/` or `rPCRsim/`, builds the panels, and writes them to `figures/`.

## Rendering

```bash
source /scicore/soft/easybuild/apps/Miniconda3/24.7.1-0/etc/profile.d/conda.sh
conda activate quarto-cli
source /scicore/soft/lmod/lmod/init/bash
module load R/4.5.2-foss-2025b R-bundle-CRAN/2025.11-foss-2025b
quarto render documents/ratioPCR_Figure_1.qmd        # and so on for the other twelve
```

`ratioPCR` itself must be installed (`R CMD INSTALL .` from the repository root); the documents
call it as a library and use three of its internals through `:::`.

`RPCR_RECALCULATE` controls the expensive chunks. Unset or `FALSE` reads the cached results;
`TRUE` recomputes them. Two caveats:

- Figures 4 and S7 recompute their calibration sweeps from `extdata/20191120AS calibration.xlsx`
  (minutes). Without recompute they need `extdata/results 2026-04-28 .rds`, which is not in git
  (142 MB) and is part of the data archive only.
- Figures 2, S5 and S6 cannot recompute in a clone: re-running the simulations needs OpenModelica
  and the `rPCR_03` model tree, which are outside this repository. They read
  `rPCRsim/<experiment>/results/results.rds`, which is tracked.

## Contents

| Path | What it is | In git |
|---|---|---|
| `ratioPCR_Figure_*.qmd` | the thirteen figure documents | yes |
| `scripts/Figure_settings.R` | shared theme, palettes, paths, `psave()`; sourced by all documents | yes |
| `scripts/omPCR_functions.R` | OpenModelica batch driver; sourced by Figures 2, S5, S6 | yes |
| `scripts/process_gel.R` | gel densitometry helpers | yes |
| `extdata/` | instrument exports and reference data read by the documents | yes, except the 142 MB cache above |
| `rPCRsim/<exp>/results/results.rds` | simulation results read by Figures 2, S5, S6 | yes |
| `rPCRsim/<exp>/settings.txt` | parameter record of each simulation batch | yes |
| `rPCRsim/<exp>/*.R` | timestamped snapshots of the notebook that produced each batch | yes |
| `rPCRsim/<exp>/model/` | copy of the compiled OpenModelica build used for that batch | no — identical across batches |
| `figures/` | rendered panels | no — regenerated by the documents |

## Provenance note

The documents were consolidated from an earlier set of per-figure R scripts and a single
manuscript-wide Quarto file. Those files are not part of this deposit: each document now carries
the code that produces its own panels, and the repairs made during consolidation are recorded in
the document that they affect.
